# Body Metrics

A BMI calculator with history tracking, charts, goals, and weekly reminders. Runs entirely in the browser — data stays on your device.

## Live

https://lemuelowusuansah.github.io/Body-Metrics-01/

## Features

- BMI calculation from height and weight
- Underweight / normal / overweight / obese classification
- History of entries
- Chart of BMI over time
- Weight goals
- Weekly reminders
- Dark theme
- Mobile-friendly
- Data stored in localStorage — never leaves your device

## Run locally

Open `index.html` in a browser. No install, no server.

Or serve it:

    python3 -m http.server 8000

Then open http://localhost:8000.

## Stack

Plain HTML, CSS, JavaScript. No build step.
